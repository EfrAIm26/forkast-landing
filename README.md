# Forkast Landing Page

Landing page profesional bilingüe (ES/EN) para Forkast - Plataforma de optimización de revenue para restaurantes en LATAM.

🌐 **Demo en vivo:** [forkast-landing.vercel.app](https://forkast-landing.vercel.app)

## 🚀 Características

- ✅ **React 18 + TypeScript + SWC** - Desarrollo ultrarrápido
- ✅ **Chatbot Eva con IA** - Gemini 3 Flash para ventas inteligentes
- ✅ **Bilingüe (ES/EN)** - Sistema completo de traducciones con i18next
- ✅ **100% Responsive** - Optimizado para mobile, tablet y desktop
- ✅ **Animaciones suaves** - Framer Motion para transiciones profesionales
- ✅ **SEO Optimizado** - Meta tags y estructura semántica

## 🤖 Chatbot Eva

Eva es una asistente virtual inteligente que:
- Responde preguntas sobre Forkast y sus servicios
- Califica leads automáticamente
- Agenda demos con clientes potenciales
- Habla español e inglés fluidamente
- Usa Gemini 3 Flash Preview via OpenRouter

## 📄 Páginas

### Home (/)

- React 18
- TypeScript
- Vite
- @vitejs/plugin-react-swc (Fast Refresh)

- i18next (internacionalización)

## 📦 Instalación

```bash
# Clonar repositorio
git clone https://github.com/EfrAlm26/forkast-landing.git
cd forkast-landing

# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Build para producción
npm run build

# Preview del build
npm run preview
```

## 🌐 Deploy en Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/EfrAlm26/forkast-landing)

O manualmente:

```bash
# Build
npm run build

# El directorio dist/ está listo para deploy
```
